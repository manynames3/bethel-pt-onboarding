# 애틀랜타 베델교회 찬양팀 웹사이트

브라우저에서 `index.html`을 열면 사이트를 사용할 수 있습니다.

이 로컬 프로토타입의 관리자 코드: `bethel`

관리자 수정 내용은 브라우저의 `localStorage`에 저장됩니다. 로컬 프로토타입과 내용 검토용으로는 충분하지만, 실제 공유 관리자 로그인을 만들려면 모든 사람이 같은 수정 내용을 볼 수 있도록 호스팅 백엔드나 CMS가 필요합니다.

파트별 온보딩은 `onboarding/` 폴더의 개별 페이지로 분리되어 있습니다. 홈의 온보딩 카드에서 각 파트 페이지로 이동할 수 있습니다.
